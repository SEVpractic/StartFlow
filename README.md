# StartFlow

Маленькая персональная Windows 11 utility для подготовки рабочего окружения при запуске.

Один раз настраивается, что должно происходить при старте:

1. Создать папку по шаблону.
2. Открыть определённые папки в Windows Explorer.
3. Запустить определённые приложения (возможно, от имени администратора).

## Требования

- Windows 11 (x64)
- .NET 9 SDK для сборки (проект WinUI 3 / Windows App SDK)
- Собранный `StartFlow.exe` — самодостаточный (run included), никаких зависимостей не требует

## Сборка

```powershell
dotnet restore
dotnet build StartFlow.csproj -c Release -r win-x64 --self-contained true
```

Результат появится в:

```text
bin\Release\net9.0-windows10.0.26100.0\win-x64\StartFlow.exe
```

## Запуск GUI

```text
StartFlow.exe
```

Открывается окно приложения с двумя экранами: **Обзор** и **Настройки**.

## Запуск silent mode

```text
StartFlow.exe --silent
```

Окно GUI не показывается, конфигурация выполняется, процесс завершается.

Exit code:

- `0` — все операции выполнены;
- `1` — были ошибки;
- `2` — критическая ошибка.

Другие аргументы:

```text
StartFlow.exe --help
```

## Расположение JSON

Файл конфигурации `startflow.json` лежит рядом с исполняемым файлом.

Если файла нет — при первом запуске создаётся корректная конфигурация по умолчанию (пустая, без записей). Если файл повреждён — он сохраняется как `startflow.json.bad`, а приложение создаёт конфигурацию по умолчанию и показывает предупреждение в GUI.

Пример:

```json
{
  "folderGeneration": {
    "enabled": true,
    "path": "D:\\Homework",
    "template": "Homework {date}"
  },
  "foldersToOpen": [
    {
      "path": "D:\\Homework",
      "enabled": true
    }
  ],
  "programs": [
    {
      "name": "Visual Studio",
      "path": "C:\\Program Files\\Microsoft Visual Studio\\2022\\Community\\Common7\\IDE\\devenv.exe",
      "args": "",
      "runAsAdmin": true,
      "skipIfRunning": true,
      "processName": "devenv",
      "enabled": true
    }
  ]
}
```

В шаблоне имени поддерживается подстановка `{date}` — текущая дата в формате `дд.ММ.гггг` (например, `Homework 17.09.2026`).

## Создание ярлыка для автозапуска окружения

1. Найдите `StartFlow.exe` в папке сборки.
2. Кликните правой кнопкой → **Показать дополнительные параметры** → **Создать ярлык**.
3. Перенесите ярлык на рабочий стол.
4. Кликните ярлык правой кнопкой → **Свойства**.
5. В поле **Объект** добавьте ` --silent` в конец:

   ```text
   "...\StartFlow.exe" --silent
   ```

6. Нажмите **ОК**.

Теперь двойной клик по ярлыку выполняет полный запуск рабочего окружения без окна StartFlow.

## `runAsAdmin`

Если у приложения включён `runAsAdmin: true`, оно запускается через Windows Shell с verb `runas`. UAC не обходится — Windows покажет стандартный запрос подтверждения.

## `skipIfRunning`

Если у приложения включён `skipIfRunning: true`, указывается `processName`, и такой процесс уже запущен — приложение пропускается (считается в «Пропущено»). Если `processName` пустой, проверка пропускается, приложение запускается. `.exe` в имени процесса не обязателен — он отбрасывается автоматически.

## Примечания

- Конфигурация не использует реестр и базы данных.
- Пользовательские данные не отправляются никуда — приложение полностью офлайн.
